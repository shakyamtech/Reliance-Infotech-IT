# Reliance Infotech Website

Official website for Reliance Infotech, showcasing our IT services, networking solutions, hardware supplies, and digital services.

**Live Demo:** [https://reliance-infotech.web.app](https://reliance-infotech.web.app)

## Features & Services

- **IT Infrastructure & Networking:** Office network setup, router/switch configuration, server installation, and cabling.
- **Hardware & Supplies:** Laptops, desktop PCs, office printers, CCTV security systems, and accessories.
- **Web & Software Development:** Business websites, custom web apps, and system integrations.
- **Maintenance & Support:** Annual maintenance contracts (AMC), on-site troubleshooting, and technical assistance.

## Built With

- HTML5 & CSS3 / SCSS
- JavaScript (ES6)
- Bootstrap
- jQuery & Plugins (Owl Carousel, ClassyNav)
- FontAwesome Icons

## Project Structure


## Running Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/shakyamtech/Reliance-Infotech-IT.git
   ```

2. Open `index.html` directly in your browser or run a simple local server:
   ```bash
   # Using Python
   python -m http.server 5500

   # Or using VS Code Live Server extension
   ```

3. Open `http://localhost:5500` in your browser.
